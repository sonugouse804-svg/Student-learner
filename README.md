## 🌟 Overview

Many students struggle with academic concepts due to dry textbooks, lack of relatable real-life analogies, and scattered study resources. **Learnora** is an open-access, student-first digital learning platform designed to make self-study intuitive and effective.

The platform follows a frictionless 5-step learning workflow:
```
Open Website ➡️ Select Board & Class ➡️ Select Subject ➡️ Select Chapter ➡️ Learn & Master Concept
```

Initially tailored for **Telangana State Board (TS SCERT & TSBIE)** students, with built-in architecture expanding to **CBSE (NCERT)** and **ICSE / Other State Boards**.

---

## 🚀 Key Features

* **🏛️ Multi-Board Curriculum Alignment**:
  * **Telangana State Board (TS SCERT / TSBIE)**: Class 6 to 10 (SSC) and Intermediate 1st & 2nd Year (MPC, BiPC, CEC).
  * **National Boards**: CBSE (NCERT) and ICSE.
* **💡 5-Tab Topic Learning Module**:
  * **⚡ In a Nutshell**: Quick 2–3 line summary with zero jargon and key takeaway bullet points.
  * **📖 Detailed Concept Breakdown**: Thorough theory with formula highlights, exam tips, and font size adjustment.
  * **🎥 Curated Video Lessons**: Responsive YouTube video embeds featuring verified explanations from top educators.
  * **✏️ Real-World Worked Examples**: Step-by-step problem-solving models with real-life applications.
  * **🧠 Interactive Knowledge Check**: Instant-feedback multiple-choice quiz with scoring and explanations.
* **🔍 Global Concept Search**: Live instant search across all classes, subjects, and units.
* **🔊 Read Aloud (Text-to-Speech)**: Integrated browser SpeechSynthesis API to read lessons aloud for auditory learners.
* **🌙 Dark / Light Mode**: Eye-friendly themes for late-night exam preparation.
* **🔖 Bookmarking System**: Save challenging topics to local storage for quick revision before exams.
* **🖨️ Printable Revision Notes**: One-click print-optimized revision sheet for offline study.

## 💻 How to Run Locally

No external build tools or `npm install` required!

1. Clone or download this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/learnora.git
   ```
2. Navigate into the folder:
   ```bash
   cd learnora
   ```
3. Open `index.html` in any web browser (Google Chrome, Microsoft Edge, Firefox, Brave).
